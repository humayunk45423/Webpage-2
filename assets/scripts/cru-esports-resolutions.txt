================================================================================
[2] STEP-BY-STEP CRU INSTALLATION & CONFIGURATION GUIDE
================================================================================

1. Open Custom Resolution Utility (CRU.exe) as Administrator.
2. Select your active display from the top dropdown (marked with active asterisk *).
3. Under "Detailed Resolutions" (Top Box), click "Add...".
4. Set:
   - Timing: Automatic (PC standard) or Manual / LCD standard
   - Active Horizontal: [Desired Width, e.g. 1728]
   - Active Vertical: [Desired Height, e.g. 1080]
   - Refresh rate: [Your monitor's refresh rate, e.g. 144Hz / 240Hz]
5. Click OK.
6. Run "restart64.exe" from the CRU folder to reload your graphics driver safely without rebooting.

================================================================================
[3] GPU SCALING SETUP (REQUIRED TO REMOVE BLACK BARS)
================================================================================

* NVIDIA USERS:
  1. Open NVIDIA Control Panel.
  2. Navigate to: Display -> Adjust desktop size and position.
  3. Select "Full-screen".
  4. Set "Perform scaling on:" to "GPU" (or "Display" if your monitor supports hardware scaling).
  5. Check "Override the scaling mode set by games and programs".
  6. Click Apply.

* AMD RADEON USERS:
  1. Open AMD Software: Adrenalin Edition.
  2. Go to Gaming -> Display.
  3. Enable "GPU Scaling".
  4. Set "Scaling Mode" to "Full panel".

* INTEL GRAPHICS USERS:
  1. Open Intel Graphics Command Center.
  2. Go to Display -> General -> Scale: Select "Stretch" / "Scale Full Screen".
